# ブロックワールド2（サバイバル）

算数の問題を解くと、**素材**と**あそぶ時間（1問20秒・最大3分）**がもらえるサバイバル型のブロックゲームです。
もらった素材を、クラフト（作業台・かまど）で道具や食べ物にして生きのびます。

- `index.html` … ゲーム本体（1ファイル。Voxelcraft をもとに日本語化・算数連携）
- `quiz/` … 算数の問題画面（面積・分数。ゲームの上に重ねて出る）
- 時間がゼロになると自動で問題画面が出ます。`M` キーでいつでも問題を解けます。
- 死んでも持ち物は消えません。右クリックのかわりに `R` キーも使えます。

## ローカルで動かす

```sh
python -m http.server 5173
# http://127.0.0.1:5173/ を開く
```
